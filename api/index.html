    Training¶

    optimized_svm.TrainingProblem ¶

    Training problem on (already scaled) features x with an RBF kernel (gamma = 1).

    size property ¶

    Number of loss terms (= dual variables).

    kernel(rows=slice(None), cols=slice(None)) ¶

    Kernel matrix between loss terms rows and cols.

    sample_kernel(rows, cols) ¶

    Kernel matrix between the samples rows and cols.

    kernel_to(z, rows=slice(None)) ¶

    Kernel matrix between loss terms rows and new (scaled) points z.

    sample_coefficients(a) ¶

    Coefficients per sample beta_k = sum_{l: k(l) = k} a_l.

    ka(a) ¶

    K a / lam per loss term (computed via the sample coefficients).

    optimized_svm.train(prob, smo_options=None, newton_options=None, alpha0=None) ¶

    Two-step training: SMO warm start followed by Newton refinement.

    For non-smooth losses (smoothing = 0) the SMO solution is already exact; for losses without SMO formulation (squared, Poisson) Newton starts at zero.

    optimized_svm.newton(prob, a, b, c, *, tol=1e-12, max_steps=100, max_backtracks=20, sigma=0.0001, beta=0.5, verbose=0) ¶

    Damped semismooth Newton method for the (smoothed) primal training problem.

    Requires a loss with (piecewise) second derivative. The 1-norm constraint is treated as active iff c > 0 at the starting point.

    optimized_svm.Solution dataclass ¶

    Solution (a, b, c) of a training problem with ka = K a / lam.

    Losses¶

    optimized_svm.losses ¶

    Loss functions of the training problem, expressed per loss term.

    A training problem with n samples consists of m loss terms: one per sample, or two for the epsilon-insensitive loss (one for each side of the tube). Term l belongs to sample kernel_index[l], has weight w_l, label y_l and sign s_l (used by the optional 1-norm constraint, 0 if not applicable). The decision value of a term is f(x_l) + s_l c.

    Terms dataclass ¶

    Term structure of a training problem.

    Loss ¶

    Base class: per-term loss phi_l(t) and its derivatives.

    HingeLoss dataclass ¶

    Bases: Loss

    Smoothed hinge loss w * m_delta(shift - y t) for labels y in {-1, +1}.

    EpsilonInsensitiveLoss dataclass ¶

    Bases: Loss

    Smoothed epsilon-insensitive loss w * (m(y - t - eps) + m(t - y - eps)).

    Uses two terms per sample: sign +1 for m(y - t - eps) and -1 for the other side.

    SquaredLoss dataclass ¶

    Bases: Loss

    Least-squares loss w / 2 * (t - y)^2 (LS-SVM).

    PoissonLoss dataclass ¶

    Bases: Loss

    Poisson negative log-likelihood w * (exp(t) - y t + log(y!)) for counts y.

    ApproxPoissonLoss dataclass ¶

    Bases: Loss

    Poisson-type loss with a linear left tail (from the original experiments):

    w * (exp(t) - (y + 1) t - 1 + log(y!)) for t > 0 and w * (-y t + log(y!)) else.

    It is convex and continuously differentiable; for t <= 0 its curvature vanishes.

    Validation losses¶

    optimized_svm.validation ¶

    Validation error measures E(f) = sum_v L_v(f_v) for the upper level problem (Sec. 9.1.4).

    All measures are differentiable so that the hyperparameter objective has a gradient.

    ValidationLoss ¶

    Returns the summed loss and its gradient w.r.t. the predictions.

    SmoothHingeValidation dataclass ¶

    Bases: ValidationLoss

    sum_v w_v m_delta(shift - y_v f_v); balanced weights both classes equally.

    SmoothAbsoluteValidation dataclass ¶

    Bases: ValidationLoss

    Smoothed absolute error sum_v m_delta(f_v - y_v) + m_delta(y_v - f_v) (Huber-like).

    SquaredValidation dataclass ¶

    Bases: ValidationLoss

    1/2 sum_v (f_v - y_v)^2.

    PoissonValidation dataclass ¶

    Bases: ValidationLoss

    Poisson deviance-type loss sum_v exp(f_v) - y_v f_v + log(y_v!).

    Kernels and smoothing¶

    optimized_svm.kernels ¶

    Gaussian kernel with feature scaling and its derivatives w.r.t. log-scalings.

    The hyperparameters of the kernel are scalings s_k > 0 of feature blocks B_k: k(x, z) = exp(-sum_k s_k^2 |x_{B_k} - z_{B_k}|^2). With a single block this is the RBF kernel with gamma = s^2; with one block per feature it is an ARD kernel. The training code works on scaled features x_{B_k} * s_k and an RBF kernel with gamma = 1.

    squared_distances(x, z) ¶

    Matrix of squared Euclidean distances |x_i - z_j|^2 (clipped at zero).

    rbf(x, z) ¶

    exp(-|x - z|^2) for already scaled features.

    rbf_with_gradient(x, z, blocks=None) ¶

    Kernel matrix and its derivatives w.r.t. the log-scalings of all blocks.

    Returns K of shape (n, m) and dK of shape (n, m, n_blocks) with dK[..., k] = d K / d log s_k = -2 K * |x_{B_k} - z_{B_k}|^2 (features already scaled).

    contract_gradient(x, z, k, left, right, blocks=None) ¶

    Bilinear forms left^T (dK / d log s_k) right with dK_k = -2 K * |x_Bk - z_Bk|^2.

    k is the kernel matrix between the (already scaled) points x and z. Same as contracting the output of :func:rbf_with_gradient, but without forming the distance matrices of the blocks: with W = K * left right^T one has sum_ij W_ij |x_i - z_j|^2 = rowsum(W) . |x|^2 + colsum(W) . |z|^2 - 2 sum(x * (W z)) per feature, so a single matrix product serves all blocks.

    scale_features(x, scaling, blocks=None) ¶

    Multiplies the features of each block by its scaling.

    optimized_svm.smooth_max ¶

    Smooth approximations of the maximum function max(0, t) (Strasdat, Sec. 4.4).

    Each approximation m_delta coincides with max(0, t) for |t| >= delta and is a polynomial on (-delta, delta). The degree determines the smoothness:

    • "2": C^1, piecewise quadratic (its conjugate is quadratic, so SMO applies),
    • "3": C^2, piecewise cubic,
    • "6": C^2, a single sextic polynomial on (-delta, delta).

    smooth_max(delta, degree='2') ¶

    Returns (m, dm, ddm): the smoothed maximum and its first two derivatives.

    delta = 0 yields the (non-smooth) maximum itself.
