Coefficients per sample beta_k = sum_{l: k(l) = k} a_l.

ka(a) ¶

optimized_svm.train(prob, smo_options=None, newton_options=None, alpha0=None) ¶

Two-step training: SMO warm start followed by Newton refinement.

For non-smooth losses (smoothing = 0) the SMO solution is already exact; for losses without SMO formulation (squared, logistic, Poisson) Newton starts at zero.

By default the SMO stage stops at the tolerance :data:ROUGH_SMO_TOL or after ROUGH_SMO_STEPS steps per loss term, whichever comes first. Passing tol or max_steps in smo_options replaces these defaults (no step budget then).

optimized_svm.newton(prob, a, b, c, *, tol=1e-12, max_steps=100, max_backtracks=20, sigma=0.0001, beta=0.5, verbose=0) ¶

Damped semismooth Newton method for the (smoothed) primal training problem.

Requires a loss with (piecewise) second derivative. The 1-norm constraint is treated as active iff c > 0 at the starting point.

optimized_svm.Solution dataclass ¶

Solution (a, b, c) of a training problem with ka = K a / lam.

Losses¶

optimized_svm.losses ¶

Loss functions of the training problem, expressed per loss term.

A training problem with n samples consists of m loss terms: one per sample, or two for the epsilon-insensitive loss (one for each side of the tube). Term l belongs to sample kernel_index[l], has weight w_l, label y_l and sign s_l (used by the optional 1-norm constraint, 0 if not applicable). The decision value of a term is f(x_l) + s_l c.

Terms dataclass ¶

Term structure of a training problem.

Loss ¶

Base class: per-term loss phi_l(t) and its derivatives.

param_ratio(name, t, terms) ¶

(d phi'_l / d p) / phi''_l at fixed t for the loss parameter p = name.

Only meaningful for terms with positive curvature; it is the sensitivity of the optimality condition a_l + phi'_l(t_l) = 0 w.r.t. p in units of t and is used by the hypergradient with respect to loss parameters.

HingeLoss dataclass ¶

Bases: Loss

Smoothed hinge loss w * m_delta(shift - y t) for labels y in {-1, +1}.

LogisticLoss dataclass ¶

Bases: Loss

Logistic loss w * log(1 + exp(-y t)) for y in {-1, +1} (Strasdat, Sec. 4.1.3).

Smooth without a smoothing parameter and strictly convex, but with positive curvature everywhere: the dual solution is dense and the dual is not a separable quadratic, so there is no SMO warm start and every Newton system has the full size n.

EpsilonInsensitiveLoss dataclass ¶

Bases: Loss

Smoothed epsilon-insensitive loss w * (m(y - t - eps) + m(t - y - eps)).

Uses two terms per sample: sign +1 for m(y - t - eps) and -1 for the other side.

SquaredLoss dataclass ¶

Bases: Loss

Least-squares loss w / 2 * (t - y)^2 (LS-SVM).

PoissonLoss dataclass ¶

Bases: Loss

Poisson negative log-likelihood w * (exp(t) - y t + log(y!)) for counts y.

ApproxPoissonLoss dataclass ¶

Bases: Loss

Poisson-type loss with a linear left tail (from the original experiments):

w * (exp(t) - (y + 1) t - 1 + log(y!)) for t > 0 and w * (-y t + log(y!)) else.

It is convex and continuously differentiable; for t <= 0 its curvature vanishes.

Hypergradient¶

optimized_svm.cv_error_and_gradient(theta, x, y, w, folds, loss, validation, blocks=None, max_asum=None, smo_options=None, newton_options=None, warm_start=None, loss_params=(), basis=None) ¶

Mean validation error over all folds and its gradient w.r.t. theta.

theta = (log lam, log s_1, ..., log s_K, log p_1, ...): regularization, kernel scalings and the values of the loss parameters named in loss_params (fields of loss such as "epsilon" or "smoothing"; they replace the values stored in loss).

warm_start is a list with one (possibly None) start vector per fold; it is updated in place with the new solutions.

With basis (one array of sample indices per fold, indices into x) every fold trains a Subspace SVM whose model is spanned by these basis points (:mod:optimized_svm.subspace); warm_start then holds expansion coefficients instead of dual variables. Loss parameters and the 1-norm constraint are not supported in that case.

optimized_svm.fold_error_and_gradient(x_train, y_train, w_train, x_val, y_val, loss, validation, lam, blocks, max_asum=None, smo_options=None, newton_options=None, alpha0=None, loss_params=()) ¶

Validation error of one fold and its gradient w.r.t. (log lam, log s_k, log p_j).

p_j are the loss parameters named in loss_params (e.g. "epsilon", "smoothing"), taken from loss. x_train/x_val must already be scaled.

Subspace SVM¶

optimized_svm.subspace ¶

Subspace SVM: training and hypergradient in a low-dimensional subspace (Strasdat, Sec. 5.3).

The model is restricted to the subspace spanned by m basis points z_1, ..., z_m::

w = sum_j beta_j phi(z_j),    f(x) = sum_j beta_j k(x, z_j) + b.

By Corollary 5.9 the dual of this problem is the standard dual with the projected kernel K_s = K_XZ K_ZZ^{-1} K_ZX (a Nystroem approximation), so a Subspace SVM is an SVM with the explicit finite-dimensional feature map psi(x) = L^{-1} k_Z(x) where K_ZZ = L L^T. The primal problem has only m + 1 unknowns,

min_{u, b}  lam/2 |u|^2 + sum_l phi_l(psi_{k(l)}^T u + b),        beta = L^{-T} u,

and is solved by a damped Newton method with systems of size m + 1 instead of n: cost O(n m^2 + m^3) per step. Losses must have positive curvature somewhere (smoothed hinge or epsilon-insensitive loss with smoothing > 0, squared, logistic, Poisson); SMO is not used.

The hypergradient of the cross-validation error w.r.t. log lam and the log kernel scalings follows from the implicit function theorem for the stationarity conditions in (beta, b); one adjoint system of size m + 1 is solved per fold (derivation in docs/theory/subspace.md).

SubspaceProblem ¶

Training problem on scaled features x restricted to the span of the basis points z (z are scaled, too).

per_sample(f) ¶

Derivatives of the loss w.r.t. the decision values f (summed over the terms of a sample) and the loss value.

SubspaceSolution dataclass ¶

Solution of a subspace problem: expansion coefficients beta w.r.t. the basis points.

choose_basis(n, m, seed=0) ¶

Random subset of m out of n sample indices (sorted).

select_basis(x, lam, tol=1.0, max_size=None) ¶

Greedy pivoted Cholesky of the RBF kernel on scaled features x.

Adds the sample with the largest remaining kernel variance until the absolute trace of the Nystroem residual tr(K - K_s) is at most tol * lam or max_size points are chosen (default max(10, n // 10)). Returns the sorted indices and the final tr(K - K_s) / lam; a value above tol means that the size limit was hit and the subspace model is not a close approximation (the study in benchmarks/subspace_params.py found a cross-validation error at most 1 % above the full model for tol = 1 and at most 14 % for tol = 10).

nystroem_residual(x, idx) ¶

Trace of the Nystroem residual tr(K - K_s) of the RBF kernel on scaled features x for the basis x[idx], i.e. n - ||psi||_F^2 with psi = K_XZ L^-T and L the Cholesky factor of the jittered K_ZZ (as in :class:SubspaceProblem). Clipped at 0.

newton_subspace(prob, beta0=None, b0=0.0, **options) ¶

Damped Newton method for the subspace problem (m + 1 unknowns).

A warm start (beta0, b0) may lie in a region where the loss is linear in all samples (tiny lam gives huge coefficients), so the Hessian is just lam I and no step is accepted. The solve is then repeated from the cold start u = 0, b = 0, which is always well-posed; a :class:ConvergenceError of the cold start is raised.

fold_error_and_gradient_subspace(x_train, y_train, w_train, z, x_val, y_val, loss, validation, lam, blocks, newton_options=None, beta0=None) ¶

Validation error of one fold and its gradient w.r.t. (log lam, log s_k) (subspace model).

x_train, z and x_val must already be scaled.

Validation losses¶

optimized_svm.validation ¶

Validation error measures E(f) = sum_v L_v(f_v) for the upper level problem (Sec. 9.1.4).

All measures are differentiable so that the hyperparameter objective has a gradient.

ValidationLoss ¶

Returns the summed loss and its gradient w.r.t. the predictions.

SmoothHingeValidation dataclass ¶

Bases: ValidationLoss

sum_v w_v m_delta(shift - y_v f_v); balanced weights both classes equally.

LogisticValidation dataclass ¶

Bases: ValidationLoss

sum_v w_v log(1 + exp(-y_v f_v)); balanced weights both classes equally.

SmoothAbsoluteValidation dataclass ¶

Bases: ValidationLoss

PoissonValidation dataclass ¶

Kernels and smoothing¶

optimized_svm.kernels ¶

Gaussian kernel with feature scaling and its derivatives w.r.t. log-scalings.

The hyperparameters of the kernel are scalings s_k > 0 of feature blocks B_k: k(x, z) = exp(-sum_k s_k^2 |x_{B_k} - z_{B_k}|^2). With a single block this is the RBF kernel with gamma = s^2; with one block per feature it is an ARD kernel. The training code works on scaled features x_{B_k} * s_k and an RBF kernel with gamma = 1.

squared_distances(x, z) ¶

Matrix of squared Euclidean distances |x_i - z_j|^2 (clipped at zero).

rbf(x, z) ¶

exp(-|x - z|^2) for already scaled features.

rbf_with_gradient(x, z, blocks=None) ¶

Kernel matrix and its derivatives w.r.t. the log-scalings of all blocks.

Returns K of shape (n, m) and dK of shape (n, m, n_blocks) with dK[..., k] = d K / d log s_k = -2 K * |x_{B_k} - z_{B_k}|^2 (features already scaled).

contract_gradient(x, z, k, left, right, blocks=None) ¶

Bilinear forms left^T (dK / d log s_k) right with dK_k = -2 K * |x_Bk - z_Bk|^2.

k is the kernel matrix between the (already scaled) points x and z. Same as contracting the output of :func:rbf_with_gradient, but without forming the distance matrices of the blocks: with W = K * left right^T one has sum_ij W_ij |x_i - z_j|^2 = rowsum(W) . |x|^2 + colsum(W) . |z|^2 - 2 sum(x * (W z)) per feature, so a single matrix product serves all blocks.

scale_features(x, scaling, blocks=None) ¶

Multiplies the features of each block by its scaling.

optimized_svm.smooth_max ¶

Smooth approximations of the maximum function max(0, t) (Strasdat, Sec. 4.4).

Each approximation m_delta coincides with max(0, t) for |t| >= delta and is a polynomial on (-delta, delta). The degree determines the smoothness:

  • "2": C^1, piecewise quadratic (its conjugate is quadratic, so SMO applies),
  • "3": C^2, piecewise cubic,
  • "6": C^2, a single sextic polynomial on (-delta, delta).

smooth_max(delta, degree='2') ¶

Returns (m, dm, ddm): the smoothed maximum and its first two derivatives.

delta = 0 yields the (non-smooth) maximum itself.
